    Help us test the MS-70CDR+

    The MS-70CDR+ pages are built from the official ZOOM manual, Effects List and Handy Guitar Lab documentation. The file format, USB manager and DSP figures are still assumptions until someone checks a patch on a real pedal.

    The new Pedal manager can connect over USB, read the memories, load a .zptc file into a selected slot, keep a backup and read the slot back after writing. Please use a free test memory: nothing is written until you confirm it.

    Nobody is expected to do everything. If you have the pedal, write to us with the time you have available; we can organise the checks together and agree on the easiest way to share the results.

    What it would take

    • The MS-70CDR+, switched on, and an iPhone or iPad with Handy Guitar Lab for MS-70CDR+.
    • A USB data cable and the adapter or connection described in the Handy Guitar Lab guide.
    • A computer with Chrome or Edge to open this site and use the Pedal manager, or a sideways tablet to download test patches and move files to the iPhone or iPad.
    • The pedal firmware version, Handy Guitar Lab version, and iPhone/iPad model and system version.

    Copying or writing a patch to the pedal overwrites that memory, so a backup of your own memories and a few free test memories would keep your presets safe. The Pedal manager also makes a backup immediately before each write.

    Test 0: Pedal Manager and one effect

    About 10 minutes. On a computer, close Handy Guitar Lab and other MIDI applications, connect the MS-70CDR+ with a USB data cable and open the Pedal manager.

    1. Press Connect the pedal, allow MIDI access and wait until the manager has read the memories.
    2. Choose a free test memory. Use Send a .zptc file to load a one-effect patch made in the builder, or send a patch already saved in My patches.
    3. Confirm the write. Check that the memory shows the expected effect, the backup appears in Backups, and the result says the memory was read back and is identical.

    Send a screenshot of the manager, the downloaded backup if it was created, and the MIDI log if anything fails. Please note the firmware version and the memory number used.

    Test 1: a generated patch on the pedal

    About 15 minutes. Make a short chain in the Patch builder with CHORUS, DELAY and REVERB, download the .zptc, then load it into a free memory with the Pedal manager or Handy Guitar Lab.

    We would need to know whether the three effects arrive in the same order, whether the app and pedal show the same parameter values, the Processor percentage, and whether the sound is clean. A screenshot of the app and the pedal display is enough.

    Test 2: a patch made in Handy Guitar Lab

    About 10 minutes. In the app, make a simple patch with one CHORUS or DELAY, leave the values visible, name it TEST CDR, then share or export the patch from the Patch Memory screen.

    We would need the exported .zptc file and the values shown for the effect. This tells us how the MS-70CDR+ writes its own files.

    Test 3: six effects in one patch

    About 15 minutes. Build a six-effect chain using low-load effects such as CHORUS, FLANGER, DELAY, ROOM REVERB, FILTER and AUTO PAN. Load it into a free memory with the Pedal manager or Handy Guitar Lab and step through the chain on the pedal.

    We would need to know how many effects Handy Guitar Lab shows after the copy, how many are reachable on the pedal, and whether the last effect is still present.

    Test 4: parameter round-trip

    About 20 minutes. Make a few one-effect patches with clearly different values: DELAY TIME and MODE, CHORUS DEPTH and RATE, and REVERB DECAY or MIX. Name each patch after the values the app shows and share the files together.

    The names and the displayed values let us compare the app’s values with the raw values in the file, especially for tempo-synced parameters.

    Test 5: Processor percentage

    About 15 minutes. Open three patches with different sizes in Handy Guitar Lab: one light patch, one medium chain and one close to the limit. Note the Processor percentage shown by the app and send the patch names and percentages.

    The site currently uses the independent zoom-zt2 catalogue as a DSP estimate. These measurements would let us calibrate it for the MS-70CDR+ instead of borrowing the MS-60B+ scale.

    Test 6: stereo and extra effects

    About 3–5 minutes per effect. If you have a stereo setup, try a few effects whose ZOOM descriptions mention MONO or STEREO and note whether the outputs behave as described. If Handy Guitar Lab offers any additional effects, a screenshot of the installed list and one single-effect patch would help identify them.

    There is no need to test every effect. A couple of representative examples are enough to tell us where the interface needs correction.
