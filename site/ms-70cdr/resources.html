About the patch files

The .zptc format was reverse-engineered from exported patches and is not supported by ZOOM. Parameters marked "unverified" use an inferred encoding. The first MS-70CDR+ exports are now available, but the format still needs generated-patch write/read-back tests on the pedal. How it was done: Technical notes.

Latest hardware report

A tester supplied seven one-effect .zptc files from an MS-70CDR+ with System 1.20, Preset 1.00, Boot 1.00 and checksum E473. Every file carries target mask 0x00040000, confirming the target used by this page.

FilesResult in StudioOrigin reported by tester

099 OPT COMP STUDIO.zptc		OPTICAL COMPRESSORPedal / Studio

097 BIT CRUSHER.zptc		BIT CRUSHERStudio / Pedal

095 REV REV.zptc		REVERSE REVERBStudio / Pedal
100 EQ7.zptcUnknown 0x020000c8Pedal: “STEREO GUITAR GRAPHIC EQ7”

The three paired effects prove that the current catalog recognizes the IDs for OPTICAL COMPRESSOR, BIT CRUSHER and REVERSE REVERB. EQ7 is a useful new catalog lead, but it is not added to the official Effects List until its parameter names, ranges and image are confirmed.

Still to check

  • Generated-patch write/read-back: the supplied files confirm exported one-effect patches, but not yet a patch generated by this Studio and written back to the pedal. Own the pedal? Help us test it.
  • Firmware catalogue: the tester confirms the target mask and three effect IDs; the remaining effect IDs and DSP figures still come from the open-source zoom-zt2 catalogue and need a real-pedal check.
  • STEREO GUITAR GRAPHIC EQ7: the pedal reports ID 0x020000c8, which is not in the current official 149-effect catalog. Its parameter layout still needs to be captured.
  • PRM2 block: only partly decoded on the MS-60B+; the rest of the patch data is copied from a reference export.

Unverified encoding

The rule from displayed value to stored value is inferred by analogy. The builder marks these parameters "unverified": check the value on the pedal after importing the patch.

Not decoded

The encoding is unknown: the builder asks for the stored value ("raw") instead of the value shown on the pedal.
