ZOOM MultiStomp Studio on your computer.

The desktop test version opens the same effects library and Patch builder in a local window. Your patches stay on this computer. The app is unsigned and unpublished as a store application.

Beta warning. This first release is for testing the desktop shell. Direct MIDI/USB support is the next layer to validate; the browser Pedal manager remains the tested route for now.

macOS installation

  1. Download the macOS ZIP and open it to extract ZOOM MultiStomp Studio.app.
  2. Drag the app to your Applications folder, then open it.
  3. Because this beta build is not code-signed, macOS may block the first launch. Control-click the app, choose Open, and confirm only if you trust this test build.

Windows installation

  1. Download the Windows ZIP and extract it somewhere you can keep it, such as your Desktop or another folder.
  2. Open the extracted folder and double-click ZOOM MultiStomp Studio.exe.
  3. Windows may show a SmartScreen warning because this beta build is not code-signed. Choose the option to view more information, then continue only if you trust this test build.

Linux installation

  1. Download the Linux ZIP and extract it.
  2. In a terminal, enter the extracted folder and make the app executable: chmod +x "ZOOM MultiStomp Studio".
  3. Start it with ./"ZOOM MultiStomp Studio". The ZIP is a portable build; it does not add a desktop launcher.
