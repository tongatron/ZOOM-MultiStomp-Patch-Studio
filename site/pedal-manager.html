Pedal manager experimental

The patches stored on the pedal next to the ones saved in this browser: read them, open them in the builder to edit them, and choose which memory each patch goes to. Before a memory is overwritten, its patch is kept as a backup you can restore. Works over USB in Chrome or Edge on a computer.
