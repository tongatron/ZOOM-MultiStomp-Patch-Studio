    Help us test

    The MS-200D+ pages are built from the official ZOOM Effects List, Patch Memory List and manual. Two things cannot be known without the pedal: the ID of most of its effects, and how its patches are stored. That is why there is no Patch builder yet. The Pedal manager can already read the memories over USB; it never writes to the pedal.

    Nobody is expected to do everything, and any single check helps. If you have the pedal, write to us with the time you could give: we organise the checks together, according to the time you have.

    The form asks for an email address so we can reply; the files come by email, as a reply.

    The short version: preparation and check 1 take about 20 minutes, and check 1 alone would tell us the most.

    What it would take

    • The MS-200D+ and a USB data cable.
    • For check 1, a computer with Chrome or Edge (the Pedal manager uses Web MIDI).
    • For checks 2–4, an iPhone or iPad with Handy Guitar Lab for MS-200D+: see the Handy Guitar Lab guide.
    • The firmware version of the pedal (the manual says how to see it) and the version of the app.

    Nothing on this site writes to the MS-200D+. Checks 2 and 4 save patches made in the app: use free memories, or back up your own patches first.

    Check 1: read every memory

    About 15 minutes. On a computer, close Handy Guitar Lab and any other MIDI app, connect the pedal with the USB cable and open the Pedal manager.

    1. Press Connect, allow MIDI access and wait until all 250 memories have been read.
    2. Press Back up all memories, then Download next to the backup: one .json file with every memory, as the pedal sent it.
    3. If something fails, copy the message the page shows.

    The memories of a pedal that was never changed hold the factory patches of the Patch Memory List, so each effect in the file can be matched with its name. Memories you changed help too: tell us which ones, and which effects they hold.

    Check 2: patches with known effects

    About 5 minutes per patch. In Handy Guitar Lab, make a patch with two effects, save it, export it and name the file after the two effects, for example EAGLE + KRAMPUS.zptc.

    Each file gives us the IDs of two effects. Any effect helps; the ones that appear in no factory patch of the Patch Memory List help the most.

    Check 3: Processor percentage

    About 10 minutes. If Handy Guitar Lab shows how much of the pedal's processing a patch uses, note the effects and the percentage of three patches with different effects.

    Check 4: two effects together

    About 10 minutes. Make a patch with two effects and export it. Then swap the two effects in the app, or change how they are combined if the app offers it, and export the patch again under a second name. The two files show where the pedal stores the order of the effects.

    What happens with the results

    The IDs go into the effects data of the site. With enough of them the MS-200D+ can get a Patch builder and My patches; writing to the pedal from the Pedal manager would come only after a test with a backup and a read-back on a real pedal, as for the MS-60B+.
